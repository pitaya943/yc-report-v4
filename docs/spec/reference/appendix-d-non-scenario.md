# 附錄 D — 不寫成 scenario 的需求

以下需求用檢查清單或專門的測試驗收。標「需補數字」的項目目前無法驗收。

| 類別 | 需求 | 驗收方式 |
| --- | --- | --- |
| 時間 | 所有使用者看到或輸入的日期時間都是 Asia/Taipei（UTC+8），包含「今天」、月底、1 月 1 日 00:00、閒置逾時、排程。 | 每個含時間的 scenario 都以台北時間寫成 |
| 金額 | 幣別 NTD；顯示加千分位；薪資金額為整數元；匯出中的負數金額以紅色顯示。 | 檢查清單 |
| 數量顯示 | 工項數量：整數不帶小數（`3`），非整數一位小數（`3.1`），表格中的 0 可留白。材料數量去掉尾端的 0。 | 檢查清單 |
| 導覽 | 登入後 ADMIN 與 OWNER 到確認頁，USER 到日報頁。側欄：所有人有歷史、材料、設定；USER 另有日報、個人統計；ADMIN 另有總表、確認、薪資、流水帳、檔案庫、大表群組（大表歷史、大表確認、大表總表）；OWNER 再多管理員管理與稽核紀錄。頂端顯示名稱與角色。側欄可收合，瀏覽器記住偏好。 | 檢查清單 |
| 回饋 | 變更類送出可顯示全頁等待；匯出與下載不可。成功或錯誤訊息約 5 秒後淡出。不可逆的動作（刪除、封存、重置庫存、作廢、批次審核）先要求確認。 | 檢查清單 |
| 分頁 | 每頁 20 列：歷史、確認、材料申請、稽核、流水帳。25 列：大表歷史。30 列：檔案庫。 | 檢查清單 |
| 庫存顏色 | 剩餘 > 5 綠色；1–5 黃色；≤ 0 紅色。剩餘 0、隱藏、暫存區的品項申請按鈕停用（伺服器另有 MAT-R03）。 | 檢查清單 |
| 匯出版面 | Excel 為 `.xlsx`；薪資 PDF 為 A4 橫式；轉帳單為板信商業銀行薪轉格式的 `.docx`；所有檔案正確顯示繁體中文。 | 以樣本檔人工比對 |
| 發薪勾選文字 | 勾選框文字：「本次為10號發薪（含固定薪資與勞健保）」。 | 檢查清單 |
| 容量 | 沒有人數上限；設計目標是舊規模（約 10 位管理員、75 位員工）的十倍以上。**需補數字**：例如 850 個帳戶、每月 18,700 筆回報下，薪資計算與歷史查詢的回應時間上限。 | 負載測試 |
| 金鑰管理 | 加密金鑰的保管與輪替屬於維運；使用者可見行為見 IAM-R43。 | 維運文件 |
| 檔案保存 | 流水帳證據檔永久保存。下載連結不得被儲存或當成長期網址使用。 | LED-R12 與程式碼審查 |
