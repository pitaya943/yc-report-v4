# 附錄 B — 欄位限制與錯誤字串

介面即時提示，伺服器一律重新驗證同一組規則。「字」以使用者看到的長度計算，一個中文字算一個字。錯誤訊息是要被斷言的完整字串，逐字相符。

同一欄位有多個訊息時，各自對應的條件看訊息本身的文字；確切的對應以各 feature 的 `Examples` 表為準。

最後五列是 `skeleton-and-sign-in` task 新增的，字串取自 v2 規格（owner 於 2026-11-21 同意）；登入群組那一列的訊息也是同時補上的。再往前的兩列是 v3 規格新增的。
