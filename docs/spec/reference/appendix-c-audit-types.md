# 附錄 C — 稽核類型

| 類別 | 類型 |
| --- | --- |
| 回報 | `REPORT_CREATE`、`REPORT_UPDATE`、`REPORT_DELETE`、`REPORT_CONFIRM`、`REPORT_REJECT`、`REPORT_UNCONFIRM` |
| 帳戶 | `ACCOUNT_CREATE`、`ACCOUNT_UPDATE`、`ACCOUNT_ARCHIVE`、`ACCOUNT_RESTORE`、`ACCOUNT_ROLE_CHANGE`、`ACCOUNT_LOCKOUT`、`PASSWORD_CHANGE`、`BANK_REVEAL` |
| 材料 | `MATERIAL_REQUEST`、`MATERIAL_CANCEL`、`MATERIAL_ADD`、`MATERIAL_UPDATE`、`MATERIAL_DELETE`、`MATERIAL_APPROVE`、`MATERIAL_REJECT`、`MATERIAL_IMPORT`、`MATERIAL_RESET`、`MATERIAL_KEEP_A`、`MATERIAL_SYNC_B` |
| 薪資與設定 | `SYSTEM_CONFIG`、`RETENTION_SET`、`RETENTION_RESET`、`RETENTION_YEAR_END` |
| 流水帳 | `LEDGER_CREATE`、`LEDGER_UPDATE`、`LEDGER_DELETE`、`LEDGER_SETTLE`、`LEDGER_VOID` |
| 橫切 | `EXPORT`、`FILE_DOWNLOAD`、`ACCESS_DENIED` |

已移除、不得出現的類型：`ACCOUNT_DELETE`、`ACCOUNT_DEACTIVATE`、`ACCOUNT_REACTIVATE`。

每列包含：台灣時間、行為者（人或 `SYSTEM`）、類型、說明文字。回報含共同作業者時，建立說明要有「共 N 人作業」。設定變更的說明要有舊值與新值。稽核紀錄永久保存，任何人不能修改或刪除。
